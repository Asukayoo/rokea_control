# AR3 双臂 MAC 柜 — 网络连通检查

依据 [`rokea_docs/rokea/AR3产品硬件安装手册-20260923.pdf`](rokea_docs/rokea/AR3产品硬件安装手册-20260923.pdf) §6.2.1.1。  
SDK 通用手册中的 `192.168.0.160` **不适用于** 本双臂 MAC 默认网口。

## 网口与默认 IP

| 网口 | 臂 | 默认 IP |
|------|----|---------|
| A-LAN1（ARM 核心板 A 网口1） | **右臂** | `192.168.1.160` |
| A-LAN2（ARM 核心板 A 网口2） | **右臂** | `192.168.2.160` |
| B-LAN1（ARM 核心板 B 网口1） | **左臂** | `192.168.1.160` |
| B-LAN2（ARM 核心板 B 网口2） | **左臂** | `192.168.2.160` |

注意：

- A-LAN1 / A-LAN2 都是**右臂**；两根线都插在 A 侧拿不到左臂。
- 左右臂默认 IP **相同**，不能未经改 IP 就接到同一交换机。

## 阶段 1：只验证右臂（A-LAN1）— 一根网线

当前推荐接线：**笔记本有线口 ↔ MAC 柜 A-LAN1**。

1. 确认 MAC 上电，网线插在 **A-LAN1**。
2. 笔记本该有线口设静态 IP（与机器人同网段）：
   - 地址：`192.168.1.100`
   - 掩码：`255.255.255.0`
   - 网关可空
3. 检查：

```bash
ip addr show          # 确认有线口为 192.168.1.100
ip route get 192.168.1.160
ping -c 4 192.168.1.160
```

| 结果 | 含义 |
|------|------|
| ping 通 | L2/L3 链路 OK，可继续 SDK 读状态 |
| 不通 | 查口是否误插 A-LAN2（应 ping `192.168.2.160`）、本机是否仍 DHCP、网线/口灯 |

若误插 **A-LAN2**，本机应设 `192.168.2.100`，再 `ping 192.168.2.160`。

## 阶段 2：SDK 读右臂状态

见 [`examples/ar3_right_arm_status`](../examples/ar3_right_arm_status)。成功标志：连接无错，打印机型/轴数与 7 维关节角。

SDK 文档索引与 API 说明见 [`sdk_overview.md`](sdk_overview.md)（官网：[docs.rokae.com/docs/SDK/cpp](https://docs.rokae.com/docs/SDK/cpp)）。

## 以后双臂同时控制

需要同时通到 **ARM A（右）** 与 **ARM B（左）**。

推荐（无需先改 IP）：

- 线 1：笔记本网口1 ↔ **A-LAN1**（右，`192.168.1.160`）
- 线 2：笔记本网口2（或 USB 网卡）↔ **B-LAN2**（左，`192.168.2.160`）
- 本机两网口分别配 `192.168.1.100`、`192.168.2.100`

不推荐：未经改 IP 把 A-LAN1 与 B-LAN1 接同一交换机（都会是 `192.168.1.160`）。

也可经 RobotAssist「设置 → 控制器设置 → 系统 IP」改一侧调试 IP 后，再共用交换机与单网口。
